# To-Do Planner

A simple to-do planner built to organize daily tasks and keep track of things that need to get done.

## Features

- Add new tasks and manage existing ones
- Edit or delete tasks
- Mark tasks as completed
- View all tasks in one place
- Organize tasks using a calendar view
- Save tasks using MongoDB

## Built With

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MongoDB

## Getting Started

To run the project on your local machine:

1. Clone this repository:

   ```bash
   git clone https://github.com/Saloni1976/Todo.git
   ```

2. Open the project folder:

   ```bash
   cd Todo
   ```

3. Install the dependencies:

   ```bash
   npm install
   ```

4. Create a `.env` file in the project folder and add your MongoDB connection string:

   ```env
   MONGO_URI=your_mongodb_connection_string
   ```

5. Start the server:

   ```bash
   npm start
   ```

6. Open `http://localhost:3000` in your browser.
